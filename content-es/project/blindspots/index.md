## La pregunta

¿Qué hace que un desarrollador no detecte un problema de seguridad en una API en la que confía?

## Mi contribución

Fui coautora de “API Blindspots: Why experienced developers write vulnerable code”, un trabajo que conecta la cognición y las diferencias individuales con la seguridad del software.

## El enfoque

Participaron 109 desarrolladores de cuatro países, quienes resolvieron ejercicios con API de Java. El equipo examinó la detección de puntos ciegos en relación con la experiencia, la confianza, las capacidades cognitivas y la personalidad.

## Los resultados

Los puntos ciegos se asociaron con una menor detección de problemas de seguridad. Una mayor experiencia o capacidad cognitiva no predijo una mejor detección; la apertura a la experiencia sí se asoció con una mayor detección.
